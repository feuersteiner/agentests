# Calendar sync: what happens next

To the product team, 23 November 2026.

Calendar sync did not ship in cycle 12, and the project stops here. Outlook two-way sync turned out
to depend on Microsoft fixing change notifications for shared calendars, which we do not control,
and the recurring-class conflicts were not finished.

We are not bringing it back as a new pitch for now: until Microsoft's notifications work for shared
calendars, a new pitch would hit the same wall. Maya will check the state of the API again in
February. The `calendar-sync` branch is archived as it is.

Cedar's next project comes from the cycle 13 betting table.
