# Tessellate for iOS and Android

The brief for the first release of the mobile apps, owned by the mobile team.

- **Launch:** 13 January 2027, in the App Store and Google Play.
- **Who it is for:** existing Tessellate users who want to check and comment on boards away from
  their desk. New users can sign up in the app too.

## What the first release does

- Sign in with the same account as the web app, or create one.
- Open, browse and search boards, add sticky notes and comments, and vote.
- Work offline on recently opened boards; changes sync when the phone is back online.

## What it does not do

- No payments in the app. Plans are bought and managed on the website.
- No push notifications, contacts access or precise location in the first release.
- No advertising and no advertising identifiers.

## Personal data

The apps use the same personal data, for the same uses, as the web app: see
`privacy/data-inventory.md`. Product analytics in the apps send the same events as the web app,
and the same opt-out under Settings > Privacy applies.
