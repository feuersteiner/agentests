# Backend Engineer: technical interview guide

For the two engineers who run stage 3. It takes 90 minutes, on video or in the office.

## Before

- Read the CV and the recruiter's phone-screen summary in Teamtailor.
- Open the pairing repository `planning-kata` and reset it to the `start` tag.

## Agenda

| Time         | What                                                                             |
| ------------ | -------------------------------------------------------------------------------- |
| 0 to 10 min  | Introductions and how the interview works                                        |
| 10 to 70 min | Pairing: add a rule that a shift may not start less than 11 hours after the last |
| 70 to 85 min | The candidate's questions                                                        |
| 85 to 90 min | Next steps                                                                       |

## What to look for

- Reads the existing code before changing it and asks about the rule's edge cases.
- Writes or runs a test before calling the change done.
- Talks through trade-offs. Finishing the exercise is not needed to do well.

## After

Each interviewer writes feedback in Teamtailor before talking to the other: a recommendation
(strong yes, yes, no or strong no) and the evidence for it. Questions about salary or the offer go
to the recruiter.
