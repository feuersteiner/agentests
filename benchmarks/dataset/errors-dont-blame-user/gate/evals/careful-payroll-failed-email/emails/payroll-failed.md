The payroll run scheduled for {{pay_date}} did not go through. The bank could not match the sort
code and account number saved in Ledgerline to an account, so it rejected the payment.

No money has left your account, and your {{employee_count}} employees have not been paid yet.

To run payroll again:

1. Open **Settings > Bank account** and check the sort code (6 digits) and the account number
   (8 digits) against a bank statement. Save any change.
2. Open the **Payroll** page and press **Run again**.

A run started before 15:00 on a working day pays your employees on the next working day.

If the details are right and the run fails again, reply to this email and we will look into it.
