# Partners

## Cloudnest

Cloudnest is an application hosting platform. Our contact there is Mateo Ruiz, partner marketing.

- **Integration.** The Driftlog add-on is in the Cloudnest marketplace. Installing it on a
  Cloudnest app sets the `DRIFTLOG_KEY` environment variable and forwards the app's logs and
  traces to Driftlog. No code change is needed for logs; traces need the Driftlog SDK.
- **Trace replay.** From 1 December 2026 the add-on supports trace replay: a failed request on a
  Cloudnest app can be opened in Driftlog and stepped through span by span. Replays include the
  Cloudnest router span, so the engineer sees the time a request spent in the router.
- **Offer for Cloudnest customers.** 60 days of the Driftlog Team plan free, with the code
  `CLOUDNEST60`, for workspaces created by 31 January 2027. After 60 days the workspace moves to
  the Free plan unless the customer adds a payment method.
- **Joint email.** Cloudnest sends one email about the trace replay launch to its customers in
  the first week of December. We write it, they review and send it. It is signed by both teams.
  Links go to https://driftlog.example/cloudnest.
