# Trace replay

Step through a failed request span by span, from the browser to the database. You will not find
this in any other observability tool: it is unlike anything else on the market.

## See what each span was sent

At each span you see the timing, the request and response payloads, and the log lines written
while the span was open.

## Plans

Trace replay is included in Team and Business.
