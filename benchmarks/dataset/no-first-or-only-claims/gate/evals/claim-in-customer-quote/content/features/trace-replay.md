# Trace replay

Step through a failed request span by span, from the browser to the database. At each span you
see the timing, the request and response payloads, and the log lines written while the span was
open.

> "We tried four tracing products. Driftlog is the only one that let us replay the request that
> actually failed."
> Jonas Brandt, staff engineer, Tessel Freight
