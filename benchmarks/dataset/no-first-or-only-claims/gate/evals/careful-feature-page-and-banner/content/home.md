# Logs, traces and alerts in one place

Send your logs and traces to Driftlog and search them together. Follow a request from the first
log line to the last span.

[Start on the Free plan](/signup)

## Search logs and traces together

Every log line carries the ID of the trace it belongs to. Open a trace and read its logs in
order, or start from a log line and open the request around it.

## Alerts that link to the evidence

Write an alert rule on an error rate or a latency percentile. When it fires, the alert links to
the traces that crossed the threshold.

## Sampling you control

Set a sampling rate per service. Requests that end in an error are always kept.
