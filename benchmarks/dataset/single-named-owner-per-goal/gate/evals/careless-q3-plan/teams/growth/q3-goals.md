# Growth Team — Q3 2026 Plan

## Summary

Q2 activation rose to 41% but conversion barely moved (11.8%). In Q3 we focus on getting every
trial to its own data quickly, converting more trials, and growing seats in new workspaces.

## Objective 1: Activate trials faster

**Owners:** Priya Menon & Tom Ellery

**Key result:** day-one activation from 41% to 50%

**Initiatives:**

- Guided setup checklist on the home screen (Priya, Tom)
- CSV import for stores without a web shop connector (Tom, Sam)
- Sample data workspace (TBD)

## Objective 2: Improve trial conversion

**Owner:** Growth team

**Key result:** trial-to-paid conversion from 11.8% to 13.5%

**Initiatives:**

- Trial extension when a second data source is connected (Priya, Ines)
- Last-week usage reminders (Sam)

## Objective 3: Grow seats in new workspaces

**Owner:** Ines Duarte

**Key result:** second user within 30 days from 49% to 55%

**Initiatives:**

- Move "Invite teammates" back to the dashboard (Sam, Ines)
- Daily report recipients prompt
