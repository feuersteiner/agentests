# Search your notes

Press Ctrl+K (Cmd+K on a Mac) or click the search box at the top of the sidebar, then type.

- Search looks at note titles, note text, tags and the text inside attached PDFs.
- Put words in quotes to find an exact phrase, such as `"weekly review"`.
- Type `#` and a tag name to see only notes with that tag.

We're always improving search, so keep an eye on this page for new ways to filter your notes.
