# Restore an earlier version of a note

Quillnote keeps every saved version of a note: for 7 days on Free and for 365 days on Pro and
Team.

1. Open the note and click **File > Version history**.
2. Pick a version from the list on the right. Changes are highlighted.
3. Click **Restore this version**.

Restoring a deleted notebook was added in Quillnote 4.6, released in October 2026: open
**Trash**, right-click the notebook and click **Restore**.
