# Add a table to a note

1. Put the cursor where the table should go.
2. Click **Insert > Table** and choose the number of rows and columns.
3. Press Tab to move to the next cell, and Shift+Tab to move back.

To add a row, right-click a cell and choose **Insert row below**. The current version of Quillnote
can't put a table inside another table, so use two tables one after the other.
