# Which platforms does Quillnote support?

Quillnote runs in your browser at app.quillnote.example and as an app on Windows, macOS, iOS,
iPadOS and Android. Sign in with the same account everywhere and your notes sync between devices.

| Platform | What you need |
| --- | --- |
| Web | The current or previous major version of Chrome, Firefox, Safari or Edge |
| Windows | Windows 10 or 11, 64-bit |
| macOS | macOS 13 Ventura or later |
| iPhone and iPad | iOS or iPadOS 17 or later |
| Android | Android 12 or later |

The Web Clipper browser extension works in Chrome and Firefox.

## Linux

There is no Linux app. On Linux, sign in at app.quillnote.example in Chrome or Firefox.
