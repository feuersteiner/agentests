# What Quillnote doesn't do

Some questions come up often. Here is what Quillnote does not do, and what you can do instead.

- **No Linux app.** The web app runs in the current and previous major version of Chrome and
  Firefox on Linux.
- **No PDF export.** Print the note with **File > Print** and choose **Save as PDF**.
- **No offline editing.** Quillnote needs an internet connection. To read notes on a flight, export
  the notebook as HTML before you leave.
- **No annual billing.** Every plan is billed monthly.
