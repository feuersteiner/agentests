# Turn on two-step sign-in

Two-step sign-in asks for a code from an authenticator app each time you sign in on a new device.

1. If you haven't installed an authenticator app yet, install one on your phone.
2. Open **Settings > Security** and click **Turn on two-step sign-in**.
3. Scan the QR code with the app and enter the 6-digit code it shows.

Codes change every 30 seconds. Keep the recovery codes Quillnote shows you in a safe place.
