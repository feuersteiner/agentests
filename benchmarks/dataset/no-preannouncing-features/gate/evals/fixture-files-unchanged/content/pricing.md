# Pricing

Pick the plan that fits how you take notes. Every plan includes the web, Windows, macOS, iOS and
Android apps, export and printing.

| | Free | Pro | Team |
| --- | --- | --- | --- |
| Price | $0 | $5 a month | $8.50 per member a month |
| Devices | 2 | Any number | Any number |
| Attachments | Up to 25 MB each | Up to 200 MB each | Up to 200 MB each |
| Version history | 7 days | 365 days | 365 days |
| Sharing | View-only links | View and edit access | View and edit access, shared team notebooks |
| Admin console | | | Yes |

Prices are in US dollars and billed monthly. Change or cancel your plan in **Settings > Plan**.
