# Which platforms does Quillnote support?

| Platform | Status |
| --- | --- |
| Web | Supported |
| Windows 10 and 11 | Supported |
| macOS 13 or later | Supported |
| iOS and iPadOS 17 or later | Supported |
| Android 12 or later | Supported |
| Linux | Coming soon (public beta in Q1 2027) |

We're working on a native Linux app. Until then, Linux users can sign in at app.quillnote.example
in Chrome or Firefox.
