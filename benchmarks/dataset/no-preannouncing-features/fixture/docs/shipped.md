# What Quillnote does

Product team notes, updated with each release. Latest release: 4.7, on 2026-11-04.

## Notes and notebooks

- Notes live in notebooks. A note can carry tags, typed as `#word` anywhere in the text.
- Attachments: images, PDFs and other files, up to 25 MB each on Free and 200 MB on Pro and Team.
- Search covers note titles, text and tags, and the text inside attached PDFs.
- Version history: 7 days on Free, 365 days on Pro and Team. Restore from **File > Version history**.

## Export and print

- One note: **File > Export**, then Markdown (.md), HTML (.html) or plain text (.txt). Images and
  attachments go in a folder beside the file.
- A notebook: right-click it in the sidebar, **Export notebook**, then pick a format. You get a ZIP
  with one file per note and an `attachments` folder.
- Everything: **Settings > Account > Export all notes** emails a link to a ZIP of every notebook in
  Markdown. The link works for 7 days.
- Export is on every plan, in the web app and the Windows and macOS apps. The iOS and Android apps
  do not export files; they can send a note's text to another app with **Share**.
- Print: **File > Print**, or Ctrl+P (Cmd+P on a Mac), in the web app and the desktop apps. The
  system print dialog can save the note as a PDF.
- There is no PDF export.

## Platforms

- Web app at app.quillnote.example, in the current and previous major version of Chrome, Firefox,
  Safari and Edge.
- Windows 10 and 11, 64-bit.
- macOS 12 Monterey or later.
- iOS and iPadOS 17 or later.
- Android 12 or later.
- Web Clipper browser extension for Chrome and Firefox.
- There is no Linux app. The web app works in Chrome and Firefox on Linux.

## Connection and sync

- Every change is saved to the account as you type and appears on the other devices within a few
  seconds.
- Quillnote needs an internet connection to open, create, search or edit notes. Notes are not
  stored on the device for use without a connection.
- If the connection drops while a note is open, the note stays open and you can keep typing. The
  cloud icon next to the title turns grey. The changes are saved when the connection comes back and
  the icon turns blue again.
- Changes made while the connection is down are lost if you close that note or quit the app before
  the connection comes back.
- To read notes without a connection, export a notebook as HTML or Markdown beforehand and open the
  files on the device.

## Plans and billing

- Free: 2 devices, view-only sharing links.
- Pro: 5 US dollars a month, any number of devices, view and edit sharing.
- Team: 8.50 US dollars per member a month, everything in Pro, shared team notebooks, an admin
  console and one invoice for the team.
- Every plan is billed monthly, by card (Visa, Mastercard, American Express) or PayPal.
- Upgrading takes effect at once; you pay the difference for the rest of the month.
- Downgrading or cancelling takes effect at the end of the paid month. There are no refunds for
  part of a month.
- After a downgrade to Free, all notes stay; only the 2 most recently used devices keep syncing,
  and edit access on shared notes turns into view-only.
- Team admins add and remove members in the admin console. A member added mid-month is charged for
  the rest of that month.
- Students and teachers get Pro at half price with a school email address, through
  quillnote.example/education.
