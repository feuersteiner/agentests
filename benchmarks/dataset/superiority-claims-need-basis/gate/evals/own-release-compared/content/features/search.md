# Search

Press `/` on any board to search. Search looks at card titles, owners, labels, checklists and
comments, across every board you can open.

## What changed in November 2026

Search now returns results as you type and is quicker than it was in the October release: the
index is updated when a card is saved, not once an hour. The results list also shows more of
each comment than before.
