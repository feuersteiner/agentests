# The leading automation engine for project teams

Orbitly automations are best-in-class. Write a rule once and it runs every time.

## How a rule works

A rule has a trigger and one or more actions: when a card enters Review, assign the reviewer,
set the due date to three days from now and post to the Slack channel.

## Runs

Team includes 250 automation runs a month. Business and Enterprise have no cap.
