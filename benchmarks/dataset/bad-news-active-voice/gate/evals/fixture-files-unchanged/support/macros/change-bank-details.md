Hi {{ticket.requester.first_name}},

You can change the account we take payroll from under **Settings > Bank account**:

1. Select **Change account**.
2. Enter the new sort code and account number.
3. Confirm with the code we text to the account holder.

We use the new account from your next payroll run. For a run that is already scheduled, make the
change before 15:00 on the working day before pay day.
