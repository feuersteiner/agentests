# Rename a form

A form's name is shown to your workspace in **Forms** and to respondents on the form itself.

1. Open the form from **Forms**.
2. Select the form's name in the top left corner of the editor, and type the new name.
3. Press Enter to save it.

If the form is published, select **Publish** again so respondents see the new name.
