# Filter responses

A filter shows only the responses that match an answer, for example everyone who chose Business
as their plan.

1. Open the form from **Forms** and select **Responses**.
2. Select **Filter**, just below the response count.
3. Choose a field, a condition and a value, then select **Apply**.

The filter stays on until you select **Clear filter**. Exports include only the filtered responses.
