# Reorder fields

Respondents see fields in the order they have in the editor. To move a field:

1. Open the form from **Forms**, and select the field.
2. Open the field's **More** menu.
3. Select **Move to top**, **Move up**, **Move down** or **Move to bottom**.

Moving a field can break a logic rule that depends on it, because a rule can only use a field that
comes before its own. The **Logic** tab lists any rule that no longer works.
