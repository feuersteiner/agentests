# Notes you can find again

Quillnote keeps your notes in plain text and Markdown, links them to each other, and searches
all of them as you type.

## What it does

- **Write anywhere.** Apps for Mac, Windows, iOS, Android and the web.
- **Link notes.** Type `[[` to link one note to another, and see what links back.
- **Search everything.** Search covers titles, text and the words inside attached PDFs.
- **Export.** Every note exports as a Markdown file, one at a time or all together.
