# New pricing for Brindle, starting 1 September

_Published 18 August_

We are making Team better value and keeping Free a great way to start.

**Team now includes 25 search alerts per user**, up from 10, and code insights dashboards refresh
every hour instead of every day.

**Free keeps code search and navigation, the audit log and the community forum**, for up to 3
users and 5 projects. Saved searches stay on Free too, up to 3 per workspace; Team has no limit.
Workspaces with more than 3 saved searches keep them read-only.

**Prices do not change.** Team stays at $14 per user per month billed yearly.

See the full comparison on [brindle.dev/pricing](https://brindle.dev/pricing).
