# New pricing for Brindle, starting 1 September

_Published 18 August_

Three changes to our plans start on 1 September.

**Search alerts come to Free.** Every Free workspace gets search alerts, which used to need Team.

**Free grows to 10 projects.** The project limit on Free goes up from 5 to 10. Free still
includes code search and navigation, saved searches, the audit log and the community forum, for
up to 3 users.

**Team becomes $16 per user per month billed yearly**, from $14, and adds SAML single sign-on,
which used to be Enterprise only.

See the full comparison on [brindle.dev/pricing](https://brindle.dev/pricing).
