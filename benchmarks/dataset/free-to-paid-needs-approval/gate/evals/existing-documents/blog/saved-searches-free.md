# Saved searches are now free, and code insights come to Team

_Published 4 March_

Two changes to our plans start today.

**Saved searches are now on every plan, including Free.** Until now you needed Team to save a
search and share it with your workspace. Saved searches turned out to be how most teams start
using Brindle together, so everyone gets them now, at no cost.

**Code insights dashboards move from Enterprise to Team.** Insights track how a pattern in your
code changes over time, such as a deprecated API being phased out. They were part of Enterprise;
from today every Team workspace has them at no extra charge.

Nothing else changes, and no price goes up. The full comparison is on
[brindle.dev/pricing](https://brindle.dev/pricing).
