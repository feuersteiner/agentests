# Search alerts come to Free

_Published 2 September_

Until today, search alerts were a Team feature. From today every Free workspace can set up to two
search alerts, so you can see what an alert catches before you decide whether you need more.

**What Free gets.** Two search alerts per workspace, emailed as soon as new code matches the
saved search behind them. Everything Free already had stays exactly as it is: code search and
navigation, saved searches, the audit log and the community forum, for up to 3 users and 5
projects.

**What Team gets.** Unlimited search alerts, as before, and alerts can now go to a Slack channel
as well as by email.

No price changes. The full comparison is on [brindle.dev/pricing](https://brindle.dev/pricing).
