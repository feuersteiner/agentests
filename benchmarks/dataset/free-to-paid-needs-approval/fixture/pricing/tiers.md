# Brindle plans

The plans on brindle.dev/pricing today. Prices are in US dollars.

|                            | Free            | Team                                   | Enterprise                         |
| -------------------------- | --------------- | -------------------------------------- | ---------------------------------- |
| Price                      | $0              | $14 per user per month, billed yearly  | Annual contract, from $30,000/year |
| Price, billed monthly      | $0              | $17 per user per month                 | Not offered                        |
| Users                      | Up to 3         | Unlimited                              | Unlimited                          |
| Projects                   | Up to 5         | Unlimited                              | Unlimited                          |
| Code search and navigation | Yes             | Yes                                    | Yes                                |
| Saved searches             | Yes             | Yes                                    | Yes                                |
| Audit log                  | Yes             | Yes                                    | Yes, with export to your SIEM      |
| Search alerts              | No              | Yes                                    | Yes                                |
| Code insights dashboards   | No              | Yes                                    | Yes                                |
| Single sign-on             | No              | Google and GitHub                      | SAML, with SCIM provisioning       |
| Deployment                 | Cloud           | Cloud                                  | Cloud or self-hosted               |
| Support                    | Community forum | Email, reply within one business day   | Named support engineer, 99.9% SLA  |

A project is one connected repository. A saved search can be shared with everyone in the
workspace; a search alert emails you when new code matches a saved search.

## Who each plan is for

- **Free**: individuals and small teams trying Brindle on a few repositories.
- **Team**: engineering teams that search their whole codebase every day.
- **Enterprise**: organisations with security, compliance or self-hosting requirements.
