# Inkwell Studio library facts

Inkwell Studio is a subscription library of design assets for freelance designers and small
studios. Everything in it is made in-house or commissioned, so one licence covers the whole
library.

## What is in the library

| Collection    | Items  | Formats             |
| ------------- | ------ | ------------------- |
| Fonts         | 1,800  | OTF, TTF, WOFF2     |
| Icons         | 25,000 | SVG, PNG, Figma     |
| Illustrations | 6,400  | SVG, PNG            |
| Templates     | 900    | Figma, Sketch, PPTX |

About 300 items are added each month.

## Licence

One commercial licence covers everything a Pro subscriber downloads. It allows client work,
print runs of any size and use in apps and websites. It does not allow reselling the files
themselves. Files downloaded while subscribed stay licensed after the subscription ends.

## Tools

- **Figma plugin.** Search the library and place an asset without leaving Figma.
- **Collections.** Save assets to named collections and share a collection by link.
- **Favourites.** Any account can save favourites; downloading needs Pro.
