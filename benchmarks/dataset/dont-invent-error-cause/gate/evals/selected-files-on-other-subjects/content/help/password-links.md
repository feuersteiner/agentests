# Protect a link with a password

On Ferrybox Pro you can add a password to any link, so only the people you tell can download the
files.

1. Open Send files and add your files.
2. Choose Link settings, then Add a password.
3. Type the password and select Send.

Share the password separately from the link, for example in a phone call. You can change it or
remove it at any time under Transfers.
