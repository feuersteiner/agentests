# Recurring tasks: set it and forget it

Tired of reinventing the wheel every week? Recurring tasks have your back. Whether it's the Monday
stand-up or the big push before Thanksgiving, Orbitly makes sure you never drop the ball.

## Make a task repeat

1. Open the task and select its **Due date** field.
2. Select **Repeat** and choose daily, weekly, monthly or yearly.
3. Choose when the series ends, select **Save**, and Bob's your uncle.

## What happens when you mark it as done

Orbitly creates the next task with the next due date and the same assignee, so the ball stays in
play. The checklist starts from scratch; comments are not copied.

## Public holidays

Admins can add public holidays in **Settings > Calendar**, so nobody gets a task on the Fourth of
July. A task that lands on a holiday moves to the next working day.
