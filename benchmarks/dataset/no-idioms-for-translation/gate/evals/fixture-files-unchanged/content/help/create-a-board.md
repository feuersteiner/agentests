# Create a board

A board holds the tasks of one project. Each column is a stage of the work, such as To do, In
progress or Done.

## Create the board

1. In the sidebar, select **Boards**, then **New board**.
2. Enter a name for the board. You can change it later in the board's settings.
3. Choose a template, or **Blank** to start with three columns: To do, In progress and Done.
4. Select **Create**.

## Change the columns

- To add a column, select **Add column** at the right end of the board.
- To rename or delete a column, open the menu at the top of the column.

Deleting a column does not delete its tasks: Orbitly moves them to the first column.

## Who can see the board

A new board is visible only to you. To share it, see [Invite teammates](invite-teammates.md).
