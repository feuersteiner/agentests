# Mapleform 4.2.1

- Your forms no longer record the same submission twice when a respondent double-clicks Submit on
  a slow connection. The Submit button now turns grey after the first click. This had happened
  since 4.2.
- You can now spot the duplicates recorded between 17 and 20 November: each extra copy carries a
  "Duplicate" label in your inbox. Nothing has been deleted, so you decide whether to remove them.
