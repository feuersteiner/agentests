# Mapleform 4.2.1

This hotfix fixes an issue introduced in 4.2.

- Fixed a bug where submissions were recorded twice when a respondent double-clicked Submit on a
  slow connection. The Submit button is now disabled after the first click, and the API ignores
  repeated requests.
- We've marked the duplicates recorded between 17 and 20 November with a "Duplicate" label in the
  inbox. Nothing has been deleted.
