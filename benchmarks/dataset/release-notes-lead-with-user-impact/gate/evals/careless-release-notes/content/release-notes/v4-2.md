# Mapleform 4.2

## New features

- Added a file-upload field type (PDF, JPG, PNG and DOCX, up to 10 MB per file).
- Added bulk delete to the submissions inbox, for up to 500 submissions at once.
- Slack integration now supports posting to private channels.

## Improvements

- Improved builder load time for forms with 100+ fields.
- Webhooks: failed deliveries are now retried 3 times with backoff.
- Removed the Print view from submissions (use Export > PDF instead).
- Refactored the submissions inbox query layer.
- Bumped pdfkit from 0.13 to 0.15.

## Bug fixes

- Fixed a bug where conditional logic skipped rules on questions after a page break.
- Fixed CSV export dropping the last row on forms with a page break.
