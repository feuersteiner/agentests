# Mapleform 4.2.1

- Duplicate submissions issue resolved: a form no longer records the same submission twice when a
  respondent double-clicks Submit on a slow connection.
- The duplicates recorded between 17 and 20 November have been marked with a "Duplicate" label in
  your inbox, so you can decide whether to remove them.
