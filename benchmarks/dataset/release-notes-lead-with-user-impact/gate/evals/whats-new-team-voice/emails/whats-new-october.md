Hi {{ first_name }},

October was a busy month for the Mapleform team. Here's a round-up of what we shipped.

## Page breaks

We've added page breaks, so long forms can now be split into pages, with a progress bar at the
top of each page.

## Excel export

We've made it possible to export submissions as an Excel file as well as CSV, from the Export menu
in the submissions inbox.

## Slack

We improved the Slack integration so that notifications keep going to a channel after it is
renamed.

## Dates

Date fields now accept typed dates, such as 06/10/2026, as well as dates picked from the calendar.

## Fixes

We fixed a bug that stopped forms with more than 200 fields from loading in the builder, and
another that turned accented letters into question marks in Excel exports.
