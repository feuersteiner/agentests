# agent-tests agent guide

## Layout

- `benchmarks/`: the benchmark of a rule told in a skill against the same rule enforced by agentests: its research catalogue, dataset and harness.
- `core/`: the `agentests` npm package.
- `video/`: SvelteKit app that plays and renders the 60-second silent demo film.
- `docs/`: documentation plans and use cases.
- `library/`: placeholder for the planned community library.
- `.github/workflows/`: npm publishing.
