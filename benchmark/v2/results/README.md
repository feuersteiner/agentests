# Results

Not run. No live inference, measured quality, latency, usage, or cost is available.

Real runs create ignored `raw/<timestamp>-<uuid>/` directories here. Each contains
`metadata.json`, incremental label-free `observations.jsonl`, and a final
`report.json` joining observations to provisional expectations after inference.
Raw files stay ignored. Version inspected/redacted export copies only in the
[private evidence repository](../../evidence/EVIDENCE.md), using the documented pack command.
No evidence packet text or environment values are written to results.

A report is a development-data diagnostic, not held-out performance or calibrated
quality. Errors are separate from verdicts. Missing usage and cost remain `null`.
